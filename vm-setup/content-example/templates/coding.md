# 模板：程序开发

把需求整理成一段给 Claude 的程序开发 prompt，依序包含：

1. **目标**：要完成的功能或要修的问题。
2. **已知资讯**：语言、框架、档案或错误讯息（只用需求里有的资讯）。
3. **要求**：
   - 先说明计划，再动手。
   - 修改要小、可以被检查；附上测试或验证方式。
   - 不确定 API 或参数时，先查官方文件，不要凭记忆。
4. **执行环境的安全要求**（执行环境是 Claude Code 时必须加入，原文照写）：
   - 不要执行会大量删除档案的指令，不要执行「从网络下载后直接执行」的指令，不要用系统管理员权限执行任何指令。
   - 不要把档案、程序码或资料送到外部服务；需要 git push 时，先停下来问我。
   - 不要读取或输出环境变量档、私钥或任何凭证。

   （这几句刻意不写出具体的危险指令：写出来的话，每一段 prompt 都会被 lint 标成高严重度，真正的警告反而容易被忽略。）
5. **完成的定义**：怎样算做完（例如测试全部通过）。

只输出 prompt 本身。
